# 架构、故障与可靠性机制全景

## 对象与维度

第二步首先看纯架构：容器表示包含，连接线表示已配置的连接或依赖。新任务模板中的连接为待确认的示意，不代表校准过的拓扑，也不自动建立概率关系。节点 ID 贯穿物理层级、主功能域、故障唯一归属、机制适用范围和计算结果。

主功能域可配置 compute/network/storage/facility/control/other；未配置时按对象及子层推导。功能域和物理层级是不同维度，不能再复制一套故障计账。跨域汇总不强制称为计算域。公共保存与检测开销单列，不塞到硬件源 FIT 中。

机制可跨物理对象、功能域、故障类型、生命周期、能力和效果六个维度。区分固定部署、本轮已选、未选候选；适用关系不代表所有事件都成功覆盖。明确参数的覆盖率、适用子集、条件成功率与开销；未选扩展机制不补造已启用的参数。

## 查看与导出

配置页与结果的分层诊断提供平面全景、分层空间、多维热力矩阵，支持搜索、按域/阶段/故障类型/能力/状态定位、选择查看范围、展开深度、缩放与全屏。

空间视图是物理层级的三维坐标投影，可旋转、改变俯仰和层间距；不是实际设备数字孪生，不携带几何尺寸或真实位置。默认平面纯架构，诊断时可叠加当前损失、超预算、等效 FIT 和相对对照减少的损失。矩阵比较同级或互斥叶层的故障损失、规模损失和机制适用关系。筛选仅定位，不重算或按筛选分摊总量。

界面可导出当前 SVG/PNG 及完整关联 JSON/HTML；完整导出不受当前筛选裁剪。PNG 最长边限制为 4096，密集大图优先 SVG。HTML 包含所有对象、来源、参数及数据，浏览器可打印为 PDF。正式运行报告同步包括全景及逐对象明细；Agent 用已有 report_export 导出该报告，不声称存在未实现的独立 atlas MCP 工具。

## 解释数值

数据由保存的输入与运行快照派生，不启动第二次仿真。各规模使用其真实事件目录和逐事件损失账。父层为后代汇总，功能域只加叶层，不能重复加父层。

第一轮对象改善 = 确认基线损失 − 组合损失；改进轮对象改善 = 冻结第一轮组合损失 − 本次改进损失。对象损失差值不是 Shapley，也没有对象级置信区间。全局 Shapley 保留原样，改进轮归因按本次实际改动因子，不按 FIT 比例摊成局部贡献。

灰色表示未计算、未知或含未建模对象；缺少数据不等于零风险。未观察到损失也不证明零风险。图表更细并不自动提高模型准确性，仍需要可信故障数据、数量、传播和机制参数及故障注入/实测校准。

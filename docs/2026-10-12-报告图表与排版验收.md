# 专家报告图表与排版优化

## 参考依据

逐项对照 `references/expert-review-2026-10-09/故障事件与可靠性机制收益审核.html`，对应上游 `catalogs/review-2026-10-09`，固定提交 `683afe829313bfdcb249bc593e48df5b29813666`。原始文件的哈希、逐种子进度和损失账本、4,000 条轨迹的万卡基线已有回归验证。

此前计算口径与详细数据表已参考该审核版本，视觉呈现主要是均值柱形及摘要，缺少专家报告中的趋势和敏感性曲线。本轮补齐视觉表达，不修改事件率、恢复链、Shapley 或数值引擎。

| 专家报告表达 | 本轮对应实现 |
| --- | --- |
| 对数卡数轴，基线/静默检测＋step/弹性/组合趋势 | 本次实际规模的四条曲线，带 95% 均值区间；单规模仅显示实际点 |
| 按规模查看单项与组合收益排名 | 可切换规模的有符号增益条形，带配对差值区间，负值与正值使用同一比例尺 |
| 关键假设敏感性 | 静默检出率、漏检发现时延两组实际扫描曲线，标记当前输入与目标线；纵轴局部缩放明确说明 |
| 逐事件审核和归因 | 保留完整事件库与数值列，证据等级简写；长来源、根因域和归因说明放入按需展开的宽幅明细 |

专家报告还有弹性协调暂停和 step 回滚上限的敏感性图；当前运行未扫描这些参数，因此不把专家静态图或参考数值冒充为本次结果。所有曲线仅连接已计算点，不补点、不外推。规模图的 0–100% 纵轴会截断超出物理范围的均值区间，完整区间仍在数值表和图中提示保留；敏感性图展示完整采样区间。

## 阅读与导出

结果页与 HTML 报告共用同一套图表生成器。规模对比随本次输入，结果页的收益排名随“查看规模”更新；HTML 报告也可切换收益排名规模。不同模型口径不会混画。

“独立故障事件库”末列只保留“数据证据＋查看来源”。点击可展开来源总明细并直接定位对应事件，搜索继续匹配完整来源和归因文字。所有来源默认折叠，不在数值表后重复占用大量篇幅。Markdown 使用独立来源段落，不把长说明塞进表格；JSON 冻结结构不变。

手机图表和宽数值表在各自区域内横向滑动，页面本身不溢出。打印隐藏交互控件、恢复全部被筛选的事件、展开所有来源和机制说明，来源采用“标签＋宽正文”的紧凑布局。导出 HTML 自带 SVG、样式和交互，不需要外部图表服务。

新增 `tests/e2e/report-layout.spec.ts` 在 1440px 和 390px 检查冻结数值、规模切换、来源搜索、直接定位、长来源宽度、行高、页面溢出、打印来源与事件完整性，以及平台结果页同步图表。生成真实 HTML 和 PDF 进行复核。

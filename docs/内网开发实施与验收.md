## 企业侧尚需验收

1. 公司批准的内网仓库、导入渠道、运行时与依赖来源。
2. 目标电脑断网冷安装，包括 Node/pnpm、原生 OpenCode、模型 SDK、Python/SciPy、测试浏览器。
3. 企业模型真实认证、对话、流式响应、工具调用和弱模型分步执行成功率。
4. 专用原生 Agent 配置与公司出口白名单；核查全局/上级配置和所有出站流量。
5. 企业格式解析、真实参数、故障传播假设与数值金标准。
6. 企业公共资产独立审核、多人认证授权、备份恢复及升级回滚。

## 具体限制

环境配置校验不是安全沙箱或防火墙。管理员安装的映射模块是可信代码，在 API 进程内执行。当前扩展覆盖结构化映射；通用解析器、数值求解器和报告引擎没有变成任意企业插件加载点。MCP 是可独立对接 Agent 的标准网关，依赖本地可靠性 API。工作台是本地单用户原型，多人内部服务部署需补公司身份与权限。

离线包仅覆盖当前平台 npm 依赖，原生运行时和模型 SDK 缓存需另行供给。文件摘要提供一致性检查，不能代替来源认证或公司审核。内网分支和数据不能对外同步，合成问题也只有公司批准后才能对外使用。

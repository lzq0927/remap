# 目标与MTTR核算修正

用户进一步确认万卡至五十万卡共同最低目标为98.5%；当前万卡98.5%是现状参考，未来技术增强后小规模结果可提高。参考机制参数允许按分配继续优化。

## 核查结论

- 目标推导与正向仿真必须分开。A=MTBF/(MTBF+MTTR)的反解是MTTR=MTBF×(1−A)/A；只能在同口径运行/损失周期下解释为等效MTTR。
- 万卡30h、98.5%对应1644.67s；现状按同范围线性暴露换算50万卡36min，60%对应1440s；50万卡17min、98.5%对应15.53s；45min、98.5%对应41.12s。
- 原表延长线82%是参考值，17min/82%对应223.90s，不能把15.53s标成82%的结果。
- 600h固定总窗口、98.5%对应9h损失预算正确，不应改为600×MTTR/MTBF或600/A。不同层的loss/T目标用于责任预算，不是独立物理部件可用度。
- 移除统一参考恢复预算推导不同默认目标的逻辑；各规模统一最低目标，各技术阶段分别预测结果。

## 实施

1. 共享核算函数、精简数字/百分数展示；接近100%不伪装完全检出，极小正值不展示为零。
2. 更新万卡默认目标、目标说明；不重写已存结果或用户显式目标。载入三档时保留正式目标编辑。
3. 三档输入显示正式目标与场景参考值的独立核算表，MTBF使用分钟，概率使用百分数；显式记录可用度参考卡数，兼容旧快照默认50万卡。
4. 分层诊断新增以本层hard间隔和本层目标反推的条件MTTR，标明总损失共同占用；不改动实际恢复时间或FIT。
5. 同步报告、大图、独立比较、机制参数建议和技能说明。参考初值不构成优化上限；继续使用实际参数独立复评。
6. 验证公式往返、预算守恒、历史目标不变、参考值可改善、报告/图表；走桌面与手机流程并截图。

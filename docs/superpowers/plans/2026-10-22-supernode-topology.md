# 超节点组网、规模数量与可用度关联实施计划

## 目标

在现有架构—故障—机制全景上增加可配置的1024卡超节点参考模型，支持1000/1024、10000、100000、200000、500000及自定义规模。先展示超节点内与超节点间网络、板/节点/柜的包含与连接，再叠加数量、已建模FIT、分配目标与可用度损失责任，沿用现有事件账、Shapley、AGREE与独立改进评估。

## 参考与证据边界

- 用户提供的华为云页面：https://support.huaweicloud.com/resmgmt-modelarts/resmgmt-a5_0003.html，当前检索无法读取；1024卡作为用户指定参考容量，不能声称已完整复刻该图。
- 华为官方《超节点架构创新，开源开放共筑全场景算力底座》：https://www.huawei.com/cn/news/2025/9/hc-superpod-innovation。验证了板内/板间/柜间互联、8NPU服务器和1024卡形态，但产品规格不能跨型号混用。
- 华为云资源开通文档的已索引内容区分超节点内网络性能域与超节点间网络联通域。
- 板柜密度、交换设备、端口和光模块数作为明确可编辑的工程假设，不作为官方BOM；未知值为待补充。拓扑关系不自动赋予冗余收益。
- 原库为NPU等效业务影响FIT。显示区域总事件FIT=等效FIT×卡数，不能再次乘设备数量；器件FIT仅在实际数量和参考映射有依据时折算。分层可用度是互斥损失责任投影，不能假称器件稳态可用度。

## 实施步骤

1. 增加兼容架构契约的超节点参数、数量公式与容量/利用数量解释，1024参考模型作为可选模板；原始模板和历史快照保持可读取。
2. 增加组网主视图和区域量化卡片，支持点击下钻、规模切换、纯架构/量化视图及SVG/PNG/JSON/HTML导出。区域指标与故障/机制明细复用同一数据源。
3. 将模板、数量配置和计算口径接入架构编辑、分层目标分配和正式报告；提供参数编辑和来源说明，不自动更改第一轮输入。
4. 更新Skill及说明，验证整数数量/尾部未满柜、跨规模守恒、历史兼容、预算/故障/机制关联、导出，以及桌面和手机流程并保存截图。

# 任务隔离、OpenCode 与统一流程实施验收

日期：2026-10-11。用户授权：实施上一轮需求建议与计划。工程状态：本地实现与回归通过，外部模型/环境验收保留。

## 已实现

| 问题 | 当前行为 |
|---|---|
| 会话与评估归属混乱 | 先新建/打开任务；任务独立目录、SQLite、流程、输入、资产、实验和反馈。按 URL 区分浏览器标签，主会话具名并自动恢复，专题单独新建 |
| 原生模型设置 | 使用本地官方 OpenCode UI；任务目录配置 Skill/MCP，摘要同步不触发推理。登记智谱 Coding Plan URL 与 glm-5.3，未保存用户给出的真实 Key |
| 中间与 Skill 两套流程 | 共用 WorkflowService；Agent 写阶段产物、用户签认，中央订阅持久领域事件。正式训练必须匹配当前设计、执行和版本，独立试算不能代替交付 |
| 公共资产污染 | 示例/公共只读版本复制为私有快照，记录上游摘要；用户冻结私有版本。Agent 仅提交公共候选，独立审核身份未接入时禁止发布 |
| 移植困难 | scripts 按软件根解析路径；bootstrap 不覆盖已有配置，doctor 检测可选依赖与任务 MCP。Skill manifest 和 MCP 编译入口独立，软件包与任务包分别分发 |
| 实时文件归属 | 每任务 inputs 目录独立监听，变更生成待确认输入；归档不接收，历史来源快照保留 |

任务注册表与路径边界拒绝未注册任务、越界目录、symlink/junction 和数据库副文件重定向。Agent 凭据只绑定本任务，UI 本机用户确认和 Agent 操作区分。此为单用户本地边界，尚未具备公司身份体系或企业多租户安全。

迁移不打开或改写原旧库，先验证备份，SQLite 快照包含未 checkpoint 的 WAL。每次重试独立备份目录，durable pending 标记恢复目录创建/注册/VACUUM 的中断状态。历史运行输入与摘要原样保留。

复制与导入保留固化资产/运行，当前设计重新绑定；历史引用只解析目标私有库，不访问源任务。导出不含 Agent 配置、令牌和会话。当前一任务一个活动设计；多方案通过任务复制、比较实验及设计版本历史管理。

## 验证证据

- `pnpm verify:release` 九阶段退出码均为 0：doctor、TypeScript、lint、Vitest、Web 构建、MCP 构建、浏览器、软件清单、移植。
- 设置 TEST_OPENCODE_URL 的完整验收：Vitest 135 项、浏览器 14 项通过。未连接本地 OpenCode 时默认跳过 3 项原生集成测试和 1 项原生 UI 测试。
- 本地 OpenCode 实测任务目录、Skill 命令、MCP connected、GLM 登记发现、嵌入模型菜单与 Base URL/API Key 设置入口通过。无推理摘要同步通过；没有进行真实 GLM 推理。
- 真实标准 MCP SDK 连接可创建草稿、调用实际求解器并查询结果。统一流程验证 Agent 无法签认、版本冲突、正式运行精确设计绑定、最终人工交付。
- 浏览器验证任务生命周期/隔离/刷新、参数绑定、预算签认、取消与上次结果、领域产物显示、人工门槛、当前训练结果与报告、归档 URL 恢复入口。
- 干净中文/空格目录独立安装 515 个依赖，没有借用源码 node_modules；任意 cwd、新数据根与端口、模板/本地 RBD、任务 CLI 往返、旧库迁移与编译 MCP 握手通过。
- 原生界面先探测任务目录再生成配置时，会仅刷新该目录的 OpenCode 实例；配置未改变的重复连接不刷新。配置路径检查包含悬空链接，离线准备可在重连后补加载。
- 精确证据：`artifacts/release-validation.json`、`artifacts/portability-validation.json`。测试输出计数以对应运行记录为准，后续新增测试可能改变。

软件包位于 `release/rem-prototype-0.1`（目录名称为原型系列名）；包含源码、前端构建、独立 MCP 入口、Skill、模板与文件摘要清单。包不含真实任务数据、凭据、本机 .env 和已安装依赖。

## 待验收与保留边界

1. GLM 真实账户权限、流式回答、模型驱动只读及求解工具调用未验证。原生发现不代替真实调用验收；密钥需留在本机官方配置。
2. 公共发布领域规则已测试独立审查、自审拒绝、摘要改变、证据要求。自动审批审查曾拒绝包含公共发布的整批 API 变更，认为会扩大持久数据和批准权限。已采用私有库/候选提交的安全实现；发布 HTTP 入口仍关闭，等待明确批准与独立审核身份。
3. 第二实体电脑、另一 Agent 的完整 Skill 执行、官方 Web 完全离线及 Linux/macOS 尚未验收。本机隔离目录测试不宣称跨实体机器验收。
4. 正式六阶段首先覆盖训练集群；传统 RBD/FTA/BDD/CTMC 为独立实验。AI 系统、NTN、任意传播拓扑、成本/Pareto、复杂 Scheme 和企业审核协作仍需领域与平台扩展。
5. 训练指标、专家 V4 基准和原数值引擎保持；采样区间不含模型/参数误差，示例非产品验证，未宣称超过业界水平。追踪和用户采纳数据已可记录，自动优化与定期调研未擅自开启定时任务。

# 通用参数试验与场景样例

平台操作围绕当前配置和用户问题展开，场景样例只提供可编辑的起点。

| 位置 | 当前行为 |
| --- | --- |
| 改进入口 | “新建参数方案”，选择调整对象和参数，再填写目标值；不预填指定检出率 |
| 参数范围 | 从当前模型、固定部署和所选候选措施读取；支持基础能力、成本、措施参数及分规模检查点周期 |
| 试验方式 | 可添加多项参数、撤销单项调整，或从分配建议/历史方案继续编辑；未调项沿用现状 |
| 机制概览 | 按实际集合去重，显示数量、检测/恢复/检查点等能力类别，以及固定部署和候选数量 |
| 报告与贡献 | 说明本次实际组合与参数；现状候选相对固定基线的贡献，与本次改进增量分开解释 |
| 分配建议 | 规划规模和目标遵从输入，当前未启用的常规措施不作为纯调参候选；没有可分配贡献时解释原因，仍可手动试验 |
| 样例 | 一键载入场景默认措施与参数；数量、检出率、规模及目标不成为通用流程要求 |
| Agent与Skill | 按实际任务读参数、单位和机制，依据用户指定的改动构造方案；AI样例值收在单独参考中 |

新增运行同时记录求解器实际采用的候选与固定部署集合，界面和报告优先读取该记录，避免把隐式默认与用户输入混淆。历史输入、数值结果及其原始模型口径继续保留。

除默认AI样例外，验证了仅选两项恢复/检查点措施、自定义规模与目标、非静默参数调整、多参数加入后撤销，以及基础模型未选附加措施的独立试验。桌面与手机均使用真实API计算和报告导出。数值回归用于验证实现，不能替代产品实测。

操作见[分轮评估与Agent协作指南](分轮评估与Agent协作指南.md)，AI样例边界见[场景参考](../skills/sd-dfr-remap/references/ai-cluster-example.md)。

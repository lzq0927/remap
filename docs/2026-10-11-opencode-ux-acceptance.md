# 本地官方 OpenCode 与评估流程优化验收清单

日期：2026-10-11。范围：已实现的本地单工作区原型与本轮交互优化；不表示原计划 T01—T24 全部完成。依据包括《系统可靠性工作计划》、需求澄清记录、总体设计及本轮本地 OpenCode 与流程优化设计。

## 已完成的定向接口检查

测试文件：`tests/integration/ux-api-bridge.test.ts`。本轮运行 10 项通过，包含一次已安装官方 OpenCode 的真实 HTTP 调用；定向 ESLint 与全仓 TypeScript 检查通过。

| 检查                | 结果与覆盖范围                                                                                                                                 |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| 设计保存与恢复      | 初始无设计返回 null；追加保存生成不同 ID；同一毫秒的两次保存返回最新快照；request 数组被拒绝。保存的是当前工作区设计，不是企业多项目版本系统。 |
| 可下载模板          | 训练 JSON、资产 JSON、故障模式 CSV 经真实 API 下载、导入、确认、映射后可用；模板路径采用明确白名单，`.env` 与编码目录穿越请求被拒绝。          |
| 已确认输入映射      | 未确认输入不能映射；追加确认保留旧输入；训练参数、原生配置、候选资产和未映射字段分开展示。                                                     |
| 结构化提取映射      | 架构、故障模式、机制与参数集合经真实 API 映射；已有来源与输入摘要保留。架构只是场景草稿，不自动转换成训练故障域。                              |
| 缺失与歧义          | 未解决歧义阻断；缺失发生率不补零；job-hour 的 FIT 记录保留为未映射项，不擅自换算成设备 FIT。                                                   |
| 专家 FIT 顺序       | 新种子名称、索引与值按 HBM、GPU、网络、其他一致；已发布记录采用 device-hour。                                                                  |
| 本地官方 Web 元数据 | 仅返回当前目录的关联会话及深链接；服务认证用于服务器请求，不出现在返回元数据中；外部服务附加敏感字段不回传。                                   |
| 地址与凭据边界      | 非回环 Web 地址在发起请求前被拒绝；内嵌用户名/密码 URL 被安全拒绝，错误与健康状态不泄露测试凭据。                                              |
| 上下文桥接合同      | `addContext` 和 API 桥接发送 `noReply: true`；不指定 model，不覆盖官方模型选择；会话 ID 被编码。                                               |
| 真实 noReply 行为   | 向本机已安装官方服务创建测试会话并写入公开合成上下文；随后仅有 user 消息，没有 assistant 回复。未调用付费模型，也未读取或填写真实 API Key。    |

可复查命令（PowerShell）：

```powershell
$env:TEST_OPENCODE_URL = 'http://127.0.0.1:4096'
pnpm exec vitest run tests/integration/ux-api-bridge.test.ts
```

不设置 `TEST_OPENCODE_URL` 时，真实官方服务测试明确跳过，其余九项仍执行。前九项包含本地 HTTP 协议夹具，不能代替真实模型或真实资料的验收。

## 本轮实现与原需求的对应关系

| 原需求与用户路径              | 本轮实现                                                                                       | 验收边界                                                                                                                     |
| ----------------------------- | ---------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 官方模型选择与 API 配置       | 官方 OpenCode Web iframe、设置入口、独立窗口、关联会话选择；LUI 只同步上下文和定位工具运行。   | 模型选择、Provider 与自定义 Base URL 属于官方界面；具体公司 Provider 是否连通需在用户环境验证。API Key 不由 LUI 接收或回显。 |
| 澄清→描述→方法→参数→求解→交付 | 六阶段导航、引导、人工确认记录、设计自动保存与恢复、预算失效提示。                             | 人工点击确认不等于完整语义校验、自动方法适用性证明或现实符合性认证。                                                         |
| 整体目标与子模型分配          | 当前目标/窗口进入分配输入；任务可靠度与稳态可用度分别选择；适用方法按同指标比较。              | 训练正确交付与子模型指标不同；预算和分配结果仍需显式参数映射与完整回算，不能直接相乘。                                       |
| 模式、机制、证据库可维护      | 基础字段编辑、完整 JSON、草稿/发布生命周期、明确字段绑定、旧版本选择、来源与适用条件。         | 编辑器覆盖基础字段；完整机制覆盖矩阵、依赖/互斥语义与自动适用条件匹配仍未实现。                                              |
| 调整参数后进入正式计算        | 手工编辑明确解除已发布版本绑定并记录原引用；不再静默把手工参数替换成旧库值。                   | 局部覆盖属于人工确认的设计变更；原始参数的产品真实性仍需独立证据。                                                           |
| 真实输入→确认→应用            | 模板、映射预览、候选草稿、未映射原因、来源信息；规范 CSV/XLSX 行和已确认结构提取均可进入预览。 | 任意列名或自由文本不会自动猜测；缺口交由人工补充。扫描 PDF OCR、图像框定位和提取准确度基准尚未验收。                         |
| 基线与机制方案权衡            | 中文结果、目标差距与区间、配对方案比较、搜索状态、敏感性、Shapley 表格与候选回写入口。         | 表格说明的是指定模型内的计算结果；未提供成本时不能声称成本最优；有限搜索未找到不等于数学不可行。                             |
| 风险与损失解释                | 损失账本区分实际损失、已交付工作和守恒校核；损失与保存预算对照。                               | 预算对照以平均点估计为主，不证明工程能力已验证；参数/结构不确定性未被采样区间覆盖。                                          |
| 长任务与上次结果              | 排队、进度、取消、失败、结果回退、种子重放与固定快照。                                         | 任意时刻的进程检查点续算不在本轮范围；恢复指设计恢复或基于配置重跑。                                                         |

## 浏览器与人工验收路径

以下是交付检查路径。接口测试已验证的部分见上表；浏览器步骤应以本轮实际 Playwright/人工记录为证据，不能因组件存在就标记整条路径通过。

本轮真实 Playwright 覆盖 9 条流程：训练评估/报告、取消后保留上次结果、库发布与输入确认、目标/窗口/预算/阶段刷新恢复及同指标对比、发布资产手动 GPU FIT 编辑的实际运行输入、CSV 草稿导入与旧版本选择、官方嵌入的模型菜单/提供商配置及 noReply 上下文展示、无机制列表候选回代与正式交付限制、延迟旧文件映射不覆盖当前参数或来源。原生界面测试需 `TEST_OPENCODE_URL=http://127.0.0.1:4096`；未填写真实密钥。最终结果见 artifacts/release-validation.json。截图位于 artifacts/native-opencode-models.png、artifacts/native-opencode-provider.png 与 artifacts/workbench-final.png。

在生产构建的 390px 移动宽度逐页检查全部六个页签：无页面脚本错误，页面宽度均为 390px，无整页横向溢出。表格保留内部滚动。该检查不等于完整 WCAG 审计；完整图形、键盘与屏幕阅读器验收仍需专门检查。

1. 在官方嵌入中找到模型选择、Provider 与自定义 API 入口；创建或选择关联会话；同步当前设计后确认没有自动模型回复；在官方输入框运行 `/sd-dfr-remap`，将工具 runId 定位到 LUI。
2. 配置万卡/十万卡共同目标与窗口；完成预算确认；修改目标或窗口，确认旧预算失效；进入分配工具核对当前任务输入和指标口径。
3. 从库选用已发布版本；手工修改 FIT，确认引用解除提示及实际 run 输入；创建新版后仍能选择旧发布版本，历史报告保持原快照。
4. 下载训练、库和表格模板；导入、修正、追加确认；审视映射预览与未映射原因；应用训练修改或导入候选草稿；缺失 FIT 不得成为零值。
5. 运行基线与机制方案比较；从表格读取差距、区间和限制；将候选应用到当前设计，确认应用后仍需正式重算。
6. 运行长任务、取消并回看上次完整结果；刷新后恢复设计与关联会话；失败时能定位错误与重新执行。
7. 在大屏、较窄屏及移动宽度检查全部页签、官方面板放大/独立打开、表格滚动、键盘焦点和长中文内容。
8. 导出报告并记录接受、修改或拒绝理由；确认报告区分采样精度、模型假设、参考回归和未完成的现实验证。

## 仍需明确保留的边界

- 当前为单工作区原型；企业多租户、共享权限、远程官方 Web 认证与部署不在本轮。
- 任意架构/故障传播、永久故障、多作业调度与全产品模型仍需通用模型扩展。AI 系统、NTN 入口不得借训练结果冒充已验证实例。
- 机制前置依赖、互斥、成本/Pareto、多参数不确定性、真实资料校准与留出验证没有因界面优化而自动完成。
- 文件提取的 `MODEL_*` 配置与 OpenCode Provider 是两个组件；配置官方聊天模型不代表非结构化文件自动提取已可用。
- 原始文件区域预览、完整版本差异图、复杂图形拓扑编辑、定期研究与自动优化仍需独立验收。
- 本轮真实 noReply 检查证明上下文保存与无 assistant 回复；未填真实密钥，未代用户验证公司模型、账单或真实产品数据。

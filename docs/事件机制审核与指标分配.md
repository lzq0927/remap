# 事件机制审核与指标分配

工作台新增“故障事件与可靠性机制收益审核”。按专家 `catalogs/review-2026-10-09/故障事件与可靠性机制收益审核.html` 的口径计算，生成带目录、规模收益图、独立事件库、机制详情和逐事件损失对照的自包含HTML报告。

## 两个模型口径

| 操作 | 主指标 | 期末仍有静默污染 | 默认检查点 |
|---|---|---|---|
| audit，事件与机制审核 | 保留正确进度 / 窗口理想产出 | 保留最后干净检查点 | 300秒计算 / 4秒保存 |
| training，旧V4流程 | 严格正确交付比例 | 整条轨迹交付清零 | 7200秒计算 / 10秒保存 |

新审核保存完整输入、来源与结果，可独立试算，也可通过六阶段人工确认形成正式评估。当前指标与参数由服务端 assessment 统一解释，工作台、Agent、正式运行引用同一输入版本；切换口径或修改输入后原流程失效。两个口径分别使用独立版本和回归基准，不能将其均值直接比较为同一指标的改善。

## 从设计目标到决策

1. 明确指标、任务窗口、系统结构和假设。
2. 对适用子模型分配目标：Availability用独立稳态串联乘积；Equal均分共同任务窗口故障率预算；ARINC按基线故障率等比缩放；AGREE按复杂度、任务重要度和运行时间进行加权任务可靠度近似分配。
3. AGREE采用 λᵢ=nᵢ(−ln R)/(N Eᵢ tᵢ)，Rᵢ=exp(−λᵢtᵢ)，因此回合成为 ∏Rᵢ^Eᵢ=R。重要度改变后，普通串联乘积并不保证等于目标。分配结果提供回合成检查及目标FIT，但不是工程达成证明。
4. 用硬件降低源FIT，或检测、重执行、恢复、隔离等措施落实子目标。恢复机制不能未经定义就降低源FIT。训练产出不是子模块可靠度简单相乘，需分配互斥损失预算并正向验证。
5. 对相同场景计算单项、组合和条件增益，再用Shapley分摊组合收益，检查负贡献、交互及守恒。
6. 结合成本、适用范围、证据质量和独立验证选择方案；缺少成本和工程约束时不能宣称全局最优。

Shapley对加入机制集合的不同顺序做数学平均；实际恢复链另由recoveryOrder指定。统计独立不保证收益可加，只有价值函数可加时单项之和才足够。存在执行顺序不代表采用马尔科夫模型：固定120小时兜底、周期保存和非指数恢复采用离散事件仿真；满足指数驻留时间和恒定率等条件时可选CTMC，否则可考虑半马尔科夫或扩展状态模型。

## 数据校准

审核基线有54条事件、18个硬件或根因域。中断/亚健康/静默参考比例96.6%/2%/1.4%，万卡中断MTBF30小时。所有FIT都指每十亿NPU等效运行小时的业务影响事件，不是器件物理FIT。

内网优先校准中断总量与CORE-hard等类内占比。用eventOverrides逐条更新基线FIT并记录来源；未提供的静默/亚健康保持外网先验。全量中断占比变化时，不从旧96.6%自动推算其他两类。零观测需结合暴露时长估计上界，不能直接填零。

硬件改进用candidateFitOverrides定义目标FIT；它生成“目标FIT＋所选机制”候选，与基线校准分开。检测/恢复参数用policy设置。以下仅为合成示例，不能作为内部产品数据：

```json
[{"id":"CORE-hard","fit":420,"source":"synthetic-fixture","evidence":"scenario","rateBasis":"npu-equivalent-hour"}]
```

每次运行冻结事件、参数、策略、来源commit及摘要。内部真实文件不上传外网Git，也不在外网云环境处理。

## 使用与限制

选择规模、窗口、轨迹数、所选机制和物理恢复顺序。展开高级参数可填事件更新与硬件目标。运行成功后在“实验与报告”下载HTML；全部机制详情可展开，打印时展示完整表格。

勾选多规模比较可生成万卡至五十万卡报告；Shapley枚举所选机制的全部子集，轨迹数和预计事件量有资源上限。置信区间仅计蒙特卡洛误差，不含数据和模型误差。默认只在组合包含静默检测时扫描95%/99%/99.9%全系统检出率与24/6小时兜底时延。

DP弹性是容量等效近似，尚未计入同步阻塞、重分片通信、收敛、共因故障和备用资源耗尽。工程前置条件需在内网逐项确认。

## 目标、预算与候选复核

默认万卡目标为 99%，这是需求示例，不是基线预测。多规模目标分别输入；未指定时沿用主目标，不能自动放宽。参考损失权重为停机25%、保存20%、回滚35%、期末污染10%、降速5%、局部损失5%，仅供用户分配起点，不是专家实测结论。预算总额为 `(1 − target) × hours`；报告对照六项实际损失，并列明改进核查方向。

候选筛选限于本次已选机制的全部子集；关闭 Shapley 时只比较基线和已选组合。优先筛选均值区间下限达到目标的方案，成本全部提供时在通过候选中优先低成本，否则按均值排序。成本为用户一致单位的可加估计；不含组合耦合、硬件换型成本，不是全局最优证明。

默认对筛选出的固定组合再用独立种子索引区间复核；复核结果包括均值区间和配对改善量。建议只针对主规模；点击“载入建议组合，重新确认”后重新核对所有规模，不能把主规模的结论扩展到其他规模。独立复核用于减少筛选偏差，不涵盖参数和模型不确定性。

模型版本 `review-retained-progress.v2` 修复自定义恢复顺序中“前序失败后重执行成功”的漏计耗时。专家默认链仍通过原始引擎逐轨迹与 4000 条基线复现；历史输入/结果快照保留，旧模型版本与新版本不能未经核对直接比较。

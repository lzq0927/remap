# 独立评估轮次与目标约束分配

本方案更新此前自动双轮方案的默认交互和参数反推方式。历史运行保留原输入、计算口径和结果；新建评估不再自动执行第二轮。

## 用户流程

1. 完整六阶段流程确认第一轮现状：原六项机制，静默检出覆盖率95%，不提前套用改进参数。
2. 第一轮独立计算、查看结论和Shapley、导出报告。
3. 用户单独生成AGREE分配建议。建议中的规划试算明确不是正式第二轮结果。
4. 载入建议或手动编辑，例如仅将静默检出率改成99.5%；再点击评估。每次保存独立输入、结果、结论与增量Shapley。
5. 选择同一第一轮下的多次已完成评估，生成曲线、参数、各规模结果和各轮贡献排名的横向比较。分配建议不能冒充已完成评估参与比较。

第一轮由服务端从当前任务的已完成运行读取并冻结，客户端不能替换证据。改进运行可以关联采用的分配建议；关联建议必须属于同一第一轮。历史结果不随当前编辑变化。

## 分配方法

第一轮正Shapley贡献映射为初始重要度（允许用户修改），并形成互斥的工程设计责任。AGREE分配允许责任损失，分配差额驱动分组参数的条件响应反推。这里的责任不是独立物理故障路径，不能将每一项责任预算都强行解释成必须满足的物理损失上限。

默认以50万卡98.5%总可用度为约束。检查专家机制库的作用范围、成本和参数参考，按分配责任调整现有或新增机制，然后通过组合仿真检查总目标。参考不足时可探索明确标识的工程要求；满足目标后回调参数并移除不必要的新增机制。自动分配不降低FIT。

规划采用独立种子，最终规划复核最多1024条轨迹；正式改进评估使用第一轮的主采样数与另一组种子。规划余量为剩余损失预算的2%，上限0.03个百分点，不代表统计置信度或额外业务目标。正式报告依据采样区间判定达标、低于目标或待复核。

可选择其他规模独立分配，各规模保留自己的目标。不再将所有规模最严参数合并为统一要求。第一轮贡献相对原基线，改进贡献相对冻结的第一轮；两者基准不同，分别展示。

## 完整样例验证

第一轮原参数主采样4000条，各轮正式主采样4000条，改进贡献采用64组种子、8次排列。50万卡目标98.5%：

| 方案 | 可用度均值 | 结论 |
| --- | ---: | --- |
| 原六项，静默检出率95% | 82.68164% | 低于目标 |
| 仅提高静默检出率至99.5% | 92.20504% | 低于目标 |
| AGREE分配后独立评估 | 98.50931% | 区间跨目标，需复核 |

最后方案的保存阻塞约125.49毫秒、全局恢复尝试约14.81秒、静默检出率约99.85354%。未改变FIT，专家新增措施在组合复核后被移除。其95%区间约98.4344%至98.5842%，因此不能宣称已稳定达标。这说明先前0.476毫秒和1.35秒并非必要条件，也不意味着当前方案是唯一或全局最优解。

该50万卡方案在其他需求规模下尚未达到各自目标，报告分别显示结果，可选择对应规模重新分配。上述结果是模型输入下的评估，工程参数仍需产品验证。

完整证据位于 artifacts/separate-rounds/verification.json；各轮独立HTML/ZIP及comparison-report.html保存对应运行快照。桌面与手机测试覆盖分开执行、单项改进、来源不变、建议关联、三次比较、导出和六阶段交付。

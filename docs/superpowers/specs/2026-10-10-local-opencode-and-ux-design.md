# 本地 OpenCode 与评估流程优化

用户已授权直接使用本地安装 OpenCode 并全面优化原需求的实现与交互。本轮采用本地服务官方 Web iframe，不复制聊天、模型选择、凭证设置、权限问答界面。固定使用已安装 1.18.35；嵌入地址只接受回环服务。

## 关联与边界

- 通过本地 `/path`、`/session` 获取项目与会话，官方会话深链接打开关联会话。用户在官方界面选择模型、连接 Provider 或自定义 API。
- LUI 可创建/选择关联会话、将当前设计以 `noReply` 消息同步到会话、复制 `/sd-dfr-remap`。消息发送、模型调用由官方输入框完成，避免 LUI 覆盖官方选择。
- LUI 监听已关联会话的工具事件，定位 MCP 产生的运行并显示中间件/结果；保留固定输入与资产快照。官方新建的其他会话需要在关联选择器中明确选中。
- API 配置交给官方界面；不读取、回显用户凭证。文件提取模型配置与 OpenCode Provider 是不同组件，界面应说明。

## 审计优先修复

1. 专家 FIT 顺序统一为 HBM、GPU、网络、其他；修复默认资产名称，已有错误命名通过新版本修正，保留历史。
2. 手工修改参数明确解除发布资产绑定，显示有效参数与来源，避免服务器悄悄覆盖编辑。
3. 确认文件后提供映射预览、未映射字段与草稿入库，不把结构提取或表格解析等同于已经进入模型。
4. 六阶段显示当前步骤、完成记录和下一步；当前设计保存可恢复，目标/窗口变化使旧预算失效。
5. 分配先选择任务可靠度或稳态可用度；Equal/ARINC/具名 AGREE 按同指标对比，Availability 单独展示，不混同训练正确交付。
6. 提供基线/当前机制方案配对比较与候选回写；结果使用中文结论、差距、采样区间、损失账本和适用限制，完整 JSON 放详情。
7. 提供模板下载、资产版本选择、发布绑定提示、明确空态/成功反馈/错误恢复；较窄屏幕可快速打开官方 Agent。

## 验证与交付

真实本地官方 Web 检查模型选择与 Provider/自定义配置入口，不填真实密钥；浏览器验证官方嵌入、六步导航、设计恢复、预算失效、正确 FIT 编辑、文件映射、同指标分配对比和取消回看；针对绑定和映射编写独立回归。数值计算与专家模型公式保持，仅修正 Availability 基线指标错误。记录每项覆盖与未实现边界，不宣称完整产品准确度。

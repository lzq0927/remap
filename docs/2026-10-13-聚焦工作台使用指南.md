# 聚焦工作台使用指南

本轮在完成[现状分析与业界调研](2026-10-13-前端现状分析与业界调研.md)及[实施计划](superpowers/plans/2026-10-13-focused-workspace.md)后优化前端，不改变可靠性求解、输入单位、采样、预算分配或贡献数值。

## 从任务开始

任务主页可以按名称搜索。打开、新建、重命名、复制、归档、恢复和任务包导出/导入继续可用；搜索只过滤显示，不改任务数据。左侧六个模块按设计、分析资源、交付与连接组织；未支持的产品仍显示“待扩展”。

## 按当前步骤工作

专家口径工作台默认“按步骤”，固定六阶段导航：可用度目标、故障模式、可用度分配、可靠性措施、计算与权衡、验证与交付。直接打开历史任务也显示其保存阶段，第五步的参数核对默认折叠。阶段浏览不代表签认。

需要集中编辑时选择“全部配置”，可以再切回“按步骤”。字段保持挂载，编辑值保留；视图切换不改变设计输入修订。采样与目标/MTBF 的详细说明按需展开。历史 V4 和传统结构工具继续使用原有专用界面。

全自动流程根据真实执行事件跟随阶段，恢复步骤视图；用户仍可查看阶段记录。输入过期提示、失败和取消记录继续保留，自动完成不替代人工确认。计算阶段可独立试算；是否正式运行仍由前序确认和输入版本决定。

## 按目的阅读结果

专家结果默认“结论概览”，查看当前规模判断、可用度、95%区间、目标缺口、预算及候选复核。根据需要进入“方案收益”“可靠性框图”“贡献分摊”“风险与敏感性”；“全部分析”可集中复核所有内容。

视图切换共享同一冻结运行和当前规模，不触发重算或改变贡献排序。负值、跨零区间、条件基线追溯和收益/贡献区别保留。更换历史运行时规模回到新运行保存的规模，不沿用上一份结果的选择。

模型/组合/参数口径在可展开区。验证摘要、失败诊断和 JSON/离线 ZIP 保持[报告与附件指南](2026-10-13-报告摘要与离线技术附件.md)的口径。导出的报告仍含全部分析，工作台当前视图不会删减导出数据。

## 使用原生 OpenCode

打开 Agent 后，上方显示任务、当前模块、当前流程步骤与输入修订。主要入口是“加载 Skill 并选择执行方式”。模型选择与 API 配置仍在嵌入的本地原生 OpenCode 内操作。

“会话与连接管理”收纳会话选择/创建、专题会话、同步设计、复制 Skill 命令、官方设置、返回关联会话、刷新和独立打开。展开或收起管理区不会卸载 iframe。需要更大空间可放大面板或独立打开。

同步时服务端依据任务保存的设计生成阶段、修订和计算口径，不采信任意客户端覆盖；当前模块只接受预定义视图名称。同步不调用模型；执行方式仍由原生 Skill 对话提问选择，人工确认和公共资产审核保持原规则。

## 显示与边界

使用本机字体和现有组件，不依赖外网字体/CDN或新增 UI 包。桌面支持可收起原生 Agent，中等屏幕采用底部 Agent，手机使用单列内容和紧凑导航。宽表格/图在自身容器滚动；视图可用方向键、Home/End 切换，减少动态效果设置生效。

视图偏好是浏览器会话内显示设置，不加入任务输入、运行哈希或求解契约。任务主页和资源页未新增虚假的风险/覆盖率或自动优化结果。通用工程对象树、复杂画布编辑及按项 AI 变更审阅属于后续独立功能。
